Güemes es un proyecto personal para organizar rutinas y registrar entrenamientos, con una experiencia pensada para seguir trabajando sin conexión.

## La idea

| Función | Objetivo |
|---|---|
| Rutinas | Crear y organizar sesiones de entrenamiento. |
| Entrenamiento | Registrar ejercicios y series durante la sesión. |
| Progreso | Consultar el historial y las métricas personales. |
| Sincronización | Recuperar y compartir datos entre dispositivos al volver a conectarse. |
| Comunidad | Explorar desafíos y funciones sociales. |

## Estado y descargas

El proyecto está en desarrollo. **Todavía no hay un APK publicado en este repositorio.** Cuando exista una versión lista para compartir, aparecerá en [Releases](https://github.com/SaintWyss/guemes-app/releases).

Las funciones y la sincronización requieren más validación en dispositivos; esta página describe el proyecto y sus objetivos, no una versión de producción.

## Tecnología

React · TypeScript · FastAPI · PostgreSQL · IndexedDB · SQLite
